1. EXECUTIVE SUMMARY & SYSTEM INTEGRATION
================================================================================
The Smart Transport Monitoring system operates as a unified, offline-first edge AI
framework running on public transit buses, commercial fleets, and surveillance vehicles.

System Architecture:
- Single Video Capture (SharedVideoSource): Decodes incoming frames once and distributes
  an identical FramePacket to Module 1 (Road Defect AI), Module 2 (Traffic AI), and
  Module 3 (Incident & ANPR Intelligence).
- Single Location Service (SharedGPSService): Serves GPS telemetry fixes to all modules.
- Offline-First Edge Queue (AlertQueue): SQLite queue with background AlertSyncWorker.

Role of Module 3:
1. Trajectory Behavioral Analysis: Detects collisions, harsh braking, and swerving.
2. Emergency & Rash-Driving Routing: Routes incidents to Emergency Dispatch or Traffic Police.
3. Automatic Number Plate Recognition (ANPR):
   - Stage 1: Vehicle & License Plate Bounding Box Detection (YOLO).
   - Stage 2: Cropped Plate Character Recognition (CRNN + CTC Loss).

3. OCR MODEL ARCHITECTURE & PIPELINE (STAGE 2)
================================================================================
Model: Lightweight CRNN (CNN + BiLSTM + CTC Loss)
Input Resolution: 1 x 48 x 160 (Grayscale with aspect-ratio-preserving padding to 128)

Architecture Flow:
Input (1, 48, 160)
  ↓
CNN Feature Extractor:
  - Conv2D(1, 64) -> BatchNorm -> ReLU -> MaxPool(2,2) -> (64, 24, 80)
  - Conv2D(64, 128) -> BatchNorm -> ReLU -> MaxPool(2,2) -> (128, 12, 40)
  - Conv2D(128, 256) -> BatchNorm -> ReLU -> Conv2D(256, 256) -> BatchNorm -> ReLU -> MaxPool((2,1)) -> (256, 6, 40)
  - Conv2D(256, 512) -> BatchNorm -> ReLU -> MaxPool((2,1)) -> (512, 3, 40)
  ↓
Width Sequence Mapping:
  - Permute & Reshape: [Batch, Time=40, Features=1536 (512*3)]
  ↓
Recurrent Sequence Modeling:
  - 2-layer Bidirectional LSTM (hidden_size=256, dropout=0.1) -> [Batch, Time=40, 512]
  ↓
Character Classification:
  - Linear(512, 37) -> Logits [Time=40, Batch, Classes=37]
  ↓
CTC Loss / Greedy CTC Decoding (Blank index = 0)

Training Augmentations (Training set only):
- Mild random rotation (-5° to +5°)
- Brightness jitter (0.8 - 1.2)
- Contrast jitter (0.8 - 1.2)
- Mild Gaussian blur (radius 0.3 - 0.8)
